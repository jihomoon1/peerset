# Methodology cheat sheet (v0.4.2)

Full text: [/methodology](https://peerset.vercel.app/methodology) · source `docs/methodology.md`.

| Item          | Rule                                                                                                                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Which fact    | For each (concept, start, end), the most recently filed 10-K/10-K/A/10-Q/10-Q/A reporting exactly that period. Consolidated only. Handles restatements and amendments in one rule.                                                                                                |
| LTM           | After a 10-K: that fiscal year. After a 10-Q: **FY(prior) + YTD(current) − YTD(prior year)**, only if the period checks pass (FY 350–378 days; YTD starts the day after FY end ±7; prior YTD same length ±7, a year earlier ±10). Q4 is never derived; quarters are never summed. |
| Revenue       | `RevenueFromContractWithCustomerExcludingAssessedTax` → `Revenues` → … The highest-priority concept that has **all** LTM components.                                                                                                                                              |
| EBITDA        | Operating income + D&A from the cash-flow statement. "Standardized, unadjusted": no add-backs. No `OperatingIncomeLoss` → Unsupported (e.g. JCI).                                                                                                                                 |
| Diluted EPS   | Same LTM bridge on reported EPS. If any component period reports discontinued operations: continuing-operations EPS (0.4.0). A split since the last 10-K → P/E Unsupported; a split already in the 10-K is not (0.4.1).                                                           |
| Shares        | Cover-page `dei:EntityCommonStockSharesOutstanding`, by class; basic, not treasury-method diluted.                                                                                                                                                                                |
| Debt          | Sum of debt lines **on the balance-sheet face**. Operating leases never. An unrecognized debt-looking line → Unsupported, never guessed. A subtotal next to its parts → Unsupported. No debt lines → Reported 0 with a note.                                                      |
| Cash          | Cash, cash equivalents and short-term investments on the face. Never long-term investments. A cash line whose concept includes restricted cash counts, with a warning; restricted cash on its own line is excluded.                                                               |
| EV            | Market cap + total debt − cash. Preferred and NCI left out, with a warning when material (NCI > 5% of market cap).                                                                                                                                                                |
| NM            | Denominator ≤ 0, EV ≤ 0, or a multiple above 100.0x → NM with the reason. Missing input → "—". Method can't apply → Unsupported with the reason. Missing is never 0.                                                                                                              |
| Statistics    | Peers only (target excluded). Mean, median, high, low, 25th/75th percentile (Excel `PERCENTILE.INC`). NM, "—" and Unsupported never enter.                                                                                                                                        |
| Implied price | Target LTM metric × peer p25/median/p75 multiple → EV − debt + cash → ÷ shares. Unsupported if the metric ≤ 0, implied equity ≤ 0, or several share classes.                                                                                                                      |
| Peers         | Same 4-digit SIC, widening to 3 then 2 digits when fewer than 5 qualify. Latest-FY revenue 0.2x–5x the target's. Ranked by closeness in size; 8 by default (5–12). Financials (SIC 6000–6799), 20-F filers and filings over 200 days old are excluded.                            |
| Lag flag      | LTM end more than 75 days from the peer median LTM end.                                                                                                                                                                                                                           |
| Prices        | End-of-day closes entered by the user; a warning when more than 7 days before the analysis date.                                                                                                                                                                                  |
